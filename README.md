# Weather App

A weather application built with **HTML, CSS, JavaScript, Webpack, Node.js and Express** as part of my learning journey.

The application allows users to search for a location and view current weather information, including temperature, minimum and maximum temperatures, feels-like temperature, humidity, wind speed and weather conditions.

The app also dynamically changes its background and weather animation based on the current weather conditions.

## Features

- Search for weather by location
- Current temperature
- Maximum and minimum temperatures
- Feels-like temperature
- Humidity
- Wind speed
- Weather condition descriptions
- Dynamic weather backgrounds
- Weather-specific animated GIFs
- Fahrenheit / Celsius conversion
- Switch temperature units without making another API request
- Responsive layout
- API key protected using an Express backend
- API and network error handling
